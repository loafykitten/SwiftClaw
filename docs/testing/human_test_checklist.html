App Shell and Cross-Feature Flows

  • Do Reset notification permissions, launch the app fresh, and walk through the notification offer — try both Allow and Not Now, then relaunch.

    Why Only a person can judge whether the timing and wording feel right, and the real macOS permission prompt can't be automated.

    Technical detail

    The OS prompt must appear only after you consent in-app, and Settings must remain a recovery path if you said Not Now.

  • Do Turn on one notification source at a time (mail, review results, background chat reply, Calendar alert, Reminder alert), trigger each one, and tap the notification.

    Why Real notification delivery needs OS permission and live data — automation can't receive them.

    Technical detail

    Each notification must be useful and its tap must open the exact destination. No notification should appear while that destination is already on screen.

  • Do Deny notification permission in macOS, read the in-app warning, use its Open System Settings button, grant permission there, and come back.

    Why This crosses into System Settings, which only a person can drive, and the warning text needs a human readability check.

    Technical detail

    The in-app status must refresh without relaunching the app.

  • Do Put the mouse away — use keyboard-only navigation and VoiceOver through the main window, Settings, composer, delete dialogs, review cards, and feature editors.

    Why Whether focus order and spoken labels actually make sense is a judgment call.

    Technical detail

    Focus order, names, values, and the reasons controls are disabled must all be clear.

  • Do Nothing yet — this one is on hold.

    Why It needs a safe debug switch to fake a database failure, which doesn't exist yet; forcing a real failure would risk real data.

Home

  • Do Open the app at different times of day (and different weather) and read the greeting on Home.

    Why "Does this greeting sound natural and not weird?" is AI-quality judgment only a person can make.

    Technical detail

    It should be brief, varied, use time/daylight/weather only when relevant, and end with your preferred persona name. Requires Swift Model, location, and network.

  • Do Repeat the greeting check with location denied, then with the network off, then with no Swift Model configured.

    Why The fallback should feel normal, not broken — that's a feel check.

    Technical detail

    The fallback must appear quickly and must not mention missing context or show an error.

  • Do Read the small secondary line under the greeting a few times.

    Why Tone (cozy/witty, not robotic) is subjective.

    Technical detail

    It should be short and free of quotes, emoji, or explanations. If generation fails, the layout must stay stable with no error noise. Requires Swift Model.

  • Do Send a message from the Home screen (try one with an image attached) and read the reply in the new chat.

    Why Judging answer quality, persona, and image understanding needs a human eye.

    Technical detail

    The new conversation should preserve your original prompt and attachments. Requires configured models; use a vision model for the image case.

Notes

  • Do Connect a throwaway folder of Markdown notes (with Obsidian metadata), then add/edit/rename/remove notes from another editor.

    Why Real interop with another app (Obsidian) needs that app.

    Technical detail

    SwiftClaw must reconcile the visible note list while leaving dotfiles, .obsidian/, non-Markdown files, and symlinks untouched.

  • Do Edit the same note in SwiftClaw and another editor at once; try Keep Mine, Take Theirs, and deleting the file externally while SwiftClaw has unsaved text.

    Why This is data-safety judgment with a real second editor — the one place you can lose writing.

    Technical detail

    Keep Mine preserves the external version and creates exactly one clearly surfaced conflict copy of your SwiftClaw edits; Take Theirs discards the local buffer with no copy. Externally deleted + unsaved text: the text stays visible and the path isn't silently recreated.
